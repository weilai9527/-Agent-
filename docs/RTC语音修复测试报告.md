## 原因与修复

- 语音识别中间结果会修订已有文字，旧逻辑把不符合前缀关系的结果追加了两次。现在每句保存最后一次非空结果，并保留原有结束标记处理。[字幕处理](../frontend/src/aliyunRtc.js#L65)
- 原有语音面试官和后端各生成追问。现在后端先保存唯一的正式问题，浏览器确认旧语音任务退出后，在同一面试房间以正式题目启动下一条语音任务。确认播报后才接收本题回答。换题期间有一次短暂重新接通。[语音换题](../frontend/src/main.jsx#L5744)
- 旧评分在显式题目关联无效时会改用前一题。现在评分和新生成的报告都校验持久化题答及轮次关系，连已有缓存评分也先核对关联。[评分校验](../backend/src/main.py#L3942)

第一次真实复测中，阿里云插播播报接口返回 HTTP 200，但浏览器没有收到可确认当前题目的字幕，所以只完成一轮。最终改用已经验证能返回完整题目字幕的接通开场播报，另经确认执行一次真实复测，两轮均通过。最终真实通话后仅澄清了开场提示措辞，另跑了相关回归。
