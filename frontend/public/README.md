# Astrainterview 第四版

双击本目录的 index.html 运行。前三版保留在项目根目录、v2 和 v3 目录。

## 本版修改

移除面试空间、电话面试、能力画像、我的导航列表，以及侧栏占位。内容区改为居中宽布局，品牌标志置于页头。手机端不再显示顶部导航列表。

保留首页功能入口、各级返回按钮、日夜主题、退出登录、三级网络配置、独立文字与语音面试、PDF 预览和历史报告。

## 使用与限制

演示登录使用任意学号及至少六位演示密码。没有真实认证或 AI 后端，题目为固定演示内容，实际练习评分标注待评估。

语音模式支持本地录音、回听与重录，不转文字；需要浏览器支持和麦克风授权。题目使用浏览器合成语音播放。PDF、录音和历史记录在当前页面内存保存，刷新会清空。

layout.css 是本版新增的无导航布局。其他代码沿用第三版；运行 node check.cjs、node check-v2.cjs 和 node check-navigation.cjs 可检查基础页面、配置及返回流程。录音测试使用模拟设备，不代表真实麦克风或视觉验收。

## 自主配置交互优化

选择配置时仅更新神经网络区域的节点、连线和汇总，不再重建整页或重复播放页面入场动画。选中状态使用柔和颜色过渡；选择后停留在当前维度，点击其他维度继续。选项区和汇总区预留高度，减少布局位移。此更新直接覆盖第四版。
第四版动态反馈更新：配置选项与汇总采用短时淡入，选中项显示柔和光晕和勾选渐现，连线渐亮；不移动页面，不自动切换维度，尊重系统减少动态效果设置。
简历预览更新：PDF 阅读器默认使用 Fit 整页适配，预览框宽度跟随容器，高度随可视窗口调整，手机端缩小边距。保留卷轴展开动画，新增在新窗口查看入口。实际 PDF 缩放支持取决于浏览器内置阅读器。

## 手机 PDF 预览修复

上传后自动展开第一份简历。使用本地 PDF.js 将文件逐页渲染为 canvas，替代浏览器 iframe PDF 阅读器。页面宽度跟随框架，竖向完整展开，多页按需绘制；尺寸变化时重绘，单页分辨率限制为约 200 万像素，减少手机内存压力。支持空白加载提示、失败提示及原文件打开入口。

新增 resume-viewer.js、resume-viewer.css、vendor/pdfjs。复制或部署时需保留整个 v4 目录，不能只发送 index.html。没有远程 CDN 依赖，文件内容不上传。PDF.js 许可证保存在 vendor/pdfjs/LICENSE；渲染关闭动态表达式执行。

使用项目内实际简历通过 PDF 解码与六种框架宽度的缩放检查；尚未进行手机真机视觉验收。
